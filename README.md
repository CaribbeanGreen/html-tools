# HTML Tools

Small single-file browser tools. Each folder has one `index.html`: open it in any browser, no install or server needed.

| Tool | What it does |
|---|---|
| [`ic-a4-scan-layout`](ic-a4-scan-layout/) | Places front and back photos of a MyKad (IC) at true card size (85.6 × 53.98 mm) on an A4 page. Crop, rotate, add a watermark, then export a PDF or a 300 DPI A4 image. Photos never leave your browser. |
| [`ror2-100-tracker`](ror2-100-tracker/) | Risk of Rain 2 checklist for all 205 Steam achievements, sorted by difficulty with tips. Progress is saved in your browser. |
| [`railgunner-item-sheet`](railgunner-item-sheet/) | Risk of Rain 2 Railgunner item priorities by rarity, switchable between M99 and HH44 loadouts. Add your own item icons. |
| [`mult-item-sheet`](mult-item-sheet/) | Risk of Rain 2 MUL-T item priorities by rarity, switchable between Auto-Nailgun and Rebar Puncher. Add your own item icons. |

## Using them online

If this repo is made public, turn on **Settings → Pages → Deploy from branch → main / (root)**. Each tool then gets its own link, e.g. `https://caribbeangreen.github.io/html-tools/ic-a4-scan-layout/`.
